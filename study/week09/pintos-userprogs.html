▸3그래서 콘솔에는 두 줄이 남아 있어도 실제 비교 결과는 기대 출력과 같았습니다.

해결 · 사용자 fault의 종료 경로05 / 06

SOLUTION:
사용자 page fault가 발생하면 printf보다 먼저 thread_exit()을 호출

exception.c · page_fault()조기 종료
if (user) {
    thread_current()->exit_status = -1;
    thread_exit();
}
printf("Page fault at ...");
kill(f);
process.c · process_exit()종료 출력
if (curr->pml4 != NULL) {
    printf("%s: exit(%d)\n",
           curr->name,
           curr->exit_status);
}

page_fault → thread_exit → process_exit
두 에러 메시지는 건너뛰고 bad-read: exit(-1)만 출력된다.

exception.c · process.cEXIT PATH

두 printf를 각각 수정한 것이 아닙니다.

사용자 page fault이면 page_fault에서 exit status를 -1로 설정하고 즉시 thread_exit을 호출합니다.

▸1thread_exit이 호출한 process_exit에서 bad-read: exit(-1)을 출력합니다.

▸2따라서 Page fault 출력과 kill 호출은 건너뜁니다.
