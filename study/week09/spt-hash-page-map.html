fault 난 주소에서 struct page까지

SPT · hash · page 세 구조체의 연결. 갈림길은 page 안의 spt_elem 한 줄

필드 순서 = week09 include/vm/vm.h · hash 값 = lab/spt-probe 실행 결과 · 청록 = SPT가 엮는 고리 · 빨강 점선 = Hunk 1 이전에 없던 것

1. 누가 무엇을 가리키나

thread → spt(struct hash) → buckets[] → 서랍 list → 힙의 page 안 spt_elem

SPT는 page를 담지 않음 → page는 힙에 따로 · 서랍 list가 page 안 spt_elem만 엮음. 0x401000 = claim 끝(frame·PML4 있음) · 0x400000 = frame = NULL, PML4에도 없음

2. spt_elem · pages가 없으면

청록 고리 전부 사라짐 → page는 힙에 그대로, thread에서 page로 가는 길 없음

0x400000 fault → 커널이 page를 못 찾음 · 종료 때 free할 목록도 없음. frame·PML4 쪽은 1번과 같음 → 두 줄의 일 = page로 가는 길

3. fault 주소에서 page 찾기

내리기 → 해시 → 서랍 고르기 → 비교 → hash_entry. PML4는 보지 않음

내리기 생략 → 키 0x401234는 어느 서랍에도 없음 → NULL (make run EXTRA=-DNO_ROUND). probe의 page에는 operations가 없어서 24 대신 16
