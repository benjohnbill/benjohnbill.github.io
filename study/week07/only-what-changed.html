관찰 · 4틱 동안 바뀌는 것

4틱 동안 recent_cpu가 오르는 건 그사이 실행된 스레드뿐

tick 1A

priority = 63 − recent_cpu/4 − nice×2 · recent_cpu = 최근에 CPU를 쓴 양 (실행 중인 스레드만 매 tick +1)

"지금 스레드(B)만 계산하면?" → 4틱 안에 교체되면 A를 놓친다

그래서 바뀐 스레드들을 따로 표시해 둬야 했다

threads/thread.c · thread_tickTIME_SLICE = 4

priority는 recent_cpu로 정해지는데, 4틱 동안 recent_cpu가 오르는 건 그사이 CPU를 쓴 스레드뿐입니다. 보통 한두 개.

▸1지금 스레드만 계산하면 될 것 같지만, 4틱 안에 교체되면 앞에 돌던 스레드를 놓칩니다.

▸2그래서 바뀐 스레드들을 따로 표시해 둬야 했습니다.

처음엔 스레드마다 dirty 비트를 달았다

  1. 그런데 비트만 있으면 누가 dirty인지 보려고 결국 전체를 돈다
  2. → 바뀐 스레드를 all 리스트 맨 앞으로 모으고, 깨끗한 스레드가 나오면 멈추자
  3. 그런데 어디서 멈출지 알려면 여전히 비트가 필요하다
노션 기록 · mlfqs 튜닝시도 1 → 2

처음엔 스레드마다 dirty 비트를 달았습니다. struct 끝은 8바이트 정렬 때문에 4바이트가 비어 있어서, magic 바로 앞에 넣으면 그 빈자리에 들어가 크기가 안 늘어납니다.

▸1그런데 비트만 있으면, 누가 dirty인지 알려고 결국 전체 리스트를 다 돌아야 합니다.

▸2그래서 바뀐 스레드를 all 리스트 맨 앞으로 옮겨서, 깨끗한 스레드가 나오면 멈추게 했습니다.

▸3그런데 어디서 멈출지 알려면 여전히 비트가 필요했습니다.

결정 과정 2 · 고리를 옮기다

새 고리 대신, 이미 있는 all 고리를 옮기면 되지 않나

방법추가 메모리비트
all 리스트 앞에 모으기비트필요 (멈출 위치)
전용 리스트 + 새 dirty_elem스레드당 고리 16B + 비트필요 (중복 push 방지)
기존 all 고리로 all ↔ dirty 이동리스트 헤드 1개없음
threads/thread.c · thread_tick매 tick
t->recent_cpu = add_mixed(t->recent_cpu, 1);
list_remove(&(t->all));                  /* 어느 리스트에 있든 빠진다 */
list_push_front(&dirty_list, &(t->all));  /* 이미 dirty여도 자리만 이동 */

list_remove는 앞뒤 원소만 이어 붙이고 리스트 헤드는 보지 않는다 → 소속을 몰라도 뺄 수 있다

threads/thread.c · thread_tick / lib/kernel/list.c · list_remove시도 3 → 4

그럼 바뀐 스레드만 담는 리스트를 따로 두면 됩니다.

▸1그런데 스레드마다 고리를 하나 더 달아야 하고, 핀토스 리스트 고리는 자기가 리스트에 있는지 모르니까, 두 번 들어가는 걸 막으려면 또 비트가 필요합니다.

▸2그때 든 생각. 이미 all 고리가 있는데, 이걸 옮기면 되지 않나.

▸3list_remove는 헤드를 안 보니까 어느 리스트에 있든 빼 줍니다. 매번 뺐다 넣으면 중복이 안 생기고, 어느 리스트에 있느냐가 곧 표시가 됩니다.

동작 · tick / 4틱 / 1초

4틱마다 dirty만 계산하고, 1초에만 전체를 돈다

thread.c · dirty_update4틱마다
for (dirty_list의 각 t) {
    thread_calc_priority(t);       // 그 스레드만
    list_remove(&(t->all));
    list_push_front(&all_list, &(t->all));
    thread_reorder_ready(t);       // 그 하나만 제자리로
}
   ⋮   전체 list_sort 없음
thread.c · mlfqs_tick매 tick
if (ticks % TIME_SLICE == 0) {
    if (ticks % TIMER_FREQ == 0) {
        recalc_load_avg();
        mlfqs_update_all(); // 전체 + sort
    } else
        dirty_update();     // 바뀐 것만
    thread_check_preempt();
}
threads/thread.c · dirty_update / mlfqs_tick (요약)O(바뀐 수)

tick마다 실행 중인 스레드를 dirty로 옮깁니다. 둘 다 상수 시간입니다.

4틱마다 dirty에 있는 스레드만 다시 계산하고, 그 스레드만 ready 리스트 제자리에 넣은 뒤 all로 돌려보냅니다. 전체 정렬은 안 합니다.

▸1모든 값이 실제로 바뀌는 1초 때만 dirty를 합쳐서 전체를 한 번 돌고 정렬합니다.
