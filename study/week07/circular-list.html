list를 줄여 보자: head와 tail을 포인터로 바꾸면?

① PintOShead · tail 노드 2개
  • list 구조체가 32 B
② 포인터 head/tail내 시도
  • 삽입·삭제마다 비었나 · 맨 앞 · 맨 뒤 분기
③ Linux list_head원형 · head 노드 1개
  • 16 B · 리스트와 노드가 같은 타입

맨 뒤를 맨 앞에 이으면 끝이 없어진다. 원형 이중 연결 리스트, Linux가 쓰는 구조였다.

PintOS lib/kernel/list.c · Linux include/linux/list.h (jingeunOS 에 일부를 가져옴)
__list_add(new, prev, next) 06

원형이면 끝이 없다. 그래서 모든 삽입이 두 이웃 사이다

include/lib/kernel/list.h69 · 83 · 101 · 114
INIT_LIST_HEAD(list) {
    list->next = list;
    list->prev = list;
}

__list_add(new, prev, next) {
    next->prev = new;
    new->next  = next;
    new->prev  = prev;
    prev->next = new;
}

list_add(new, head)
  = __list_add(new, head, head->next);
list_add_tail(new, head)
  = __list_add(new, head->prev, head);

맨 앞도 맨 뒤도 결국 두 이웃 사이. 그래서 인자는 new · prev · next 3개면 된다.

PintOS 는 list_insert(before, elem) · head · tail 노드 덕에 before->prev 가 늘 있다 (list.c:157)
