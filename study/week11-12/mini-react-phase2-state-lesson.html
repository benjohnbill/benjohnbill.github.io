인스턴스 필드는 READ와 WRITE에서 어떻게 바뀌나

레슨 0001 · mini-react Phase 2 · 약 10분 · 목표: 발표에서 useState의 두 흐름을 구분해서 말하기

한 장으로 먼저

READ 렌더링 중WRITE 클릭할 때
누가App() 안의 useStatesetCount(1)
어느 인스턴스?전역 currentComponent를 본다만들어질 때 기억한 인스턴스
몇 번째 칸?전역 hookIndex를 센다만들어질 때 기억한 칸 번호
바뀌는 필드첫 렌더링에서만 hooks에 초깃값hooks[칸], 그다음 update()
WRITE가 기억에 기대는 이유: 클릭은 렌더링이 끝난 뒤에 온다. 그때 currentComponent와 hookIndex는 이 Hook을 가리킨다는 보장이 없다.

예제 컴포넌트

function App() {
  const [count, setCount] = useState(0);   // 칸 0
  const [text, setText] = useState("");    // 칸 1
  return { type: "p", props: {}, children: [String(count)] };
}
const A = new FunctionComponent(App);
A.mount();

전체 지도

아래 단계 화면은 이 트리를 위에서부터 한 줄씩 따라간다. 막히면 이 트리로 돌아와서 지금 어느 가지에 있는지 찾자.

FunctionComponent A (instance)
├─ fields
│  ├─ component = App       <- what to run each render
│  ├─ hooks = [ ... ]       <- values that must survive between runs
│  ├─ container             <- where to draw
│  └─ currentView           <- what to diff against next time
│
├─ mount()  (first render)
│  ├─ currentComponent = A  <- so useState knows whose hooks
│  ├─ hookIndex = 0         <- count calls from slot 0
│  ├─ App()
│  │  └─ useState(0)                         READ
│  │     ├─ slot = hookIndex++  (0)
│  │     ├─ hooks[0] empty -> store 0
│  │     ├─ make setCount, remembering (A, 0)  <- used later on click
│  │     └─ return [0, setCount]
│  ├─ App returns View
│  ├─ createDomFromVNode -> container    <- first time: build all DOM
│  └─ currentView = View
│
├─ update()  (every render after mount, no arguments)
│  ├─ currentComponent = A  <- same as mount()
│  ├─ hookIndex = 0         <- same as mount()
│  ├─ App()
│  │  └─ useState(0)                         READ
│  │     ├─ slot = hookIndex++  (0)
│  │     ├─ hooks[0] has a value -> keep it  <- initial 0 is ignored
│  │     ├─ make a new setCount, remembering (A, 0)
│  │     └─ return [hooks[0], setCount]
│  ├─ App returns new View
│  ├─ diffViews(currentView, new View) -> Patch[]   <- differs from mount()
│  ├─ applyPatchesToDom(container, Patch[])         <- only changed parts
│  └─ currentView = new View
│
└─ click -> setCount(1)                       WRITE
   ├─ A.hooks[0] = 1        <- uses remembered (A, 0)
   └─ A.update()            <- uses remembered A; runs the update() branch above
      └─ ... useState(0) -> hooks[0] is 1 -> count = 1
