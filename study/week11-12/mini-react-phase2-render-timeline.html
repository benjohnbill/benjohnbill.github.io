렌더링 시간표: 왜 hookIndex는 전역이고 hooks는 인스턴스에 있나

레슨 0002 · mini-react Phase 2 · 몫 2 (Rendering) · 약 10분 · 목표: 발표에서 "왜 전역인가"를 한 문장으로 말하기

뿌리: 본문은 렌더링마다 처음부터 다시 실행된다

update()는 Root Component 본문을 처음부터 다시 실행해 새 View와 새 클릭 함수를 만든다 (팀 ADR render/render-reruns-root-component-from-top, 테스트 F8). 몫 2의 다른 결정은 거의 다 이 한 문장에서 나온다.

본문이 매번 처음부터 다시 실행되니까그래서 생긴 장치
지역 변수는 렌더링이 끝나면 사라진다State는 본문 밖, 인스턴스의 hooks 칸에 둔다 (useState)
본문 밖의 칸을 매번 다시 찾아야 한다호출 순서로 칸을 찾는다 (hookIndex, 아래 시간표)
클릭 함수가 렌더링마다 새로 생긴다actions 표를 렌더링마다 통째로 갈아 끼운다 (L98, L113)
클릭 함수는 자기를 만든 렌더링의 값을 기억한다렌더링이 Error로 끝나면 옛 값을 가진 클릭 함수가 남는다 (ADR의 CAUTION, 테스트 F116)

React 문서는 같은 생각을 "State as a Snapshot"이라고 부른다: "Its props, event handlers, and local variables were all calculated using its state at the time of the render." (react.dev, State as a Snapshot). 우리 코드의 클릭 함수가 그 "event handlers"다.

한 문장 먼저

사는 기간이 사는 곳을 정한다. 렌더링과 렌더링 사이에도 남아야 하는 값은 인스턴스에, 렌더링 한 번 동안만 쓰는 값은 모듈 변수에 둔다.
값살아야 하는 기간사는 곳코드
hooks렌더링 사이에도 계속 (State를 담으니까)인스턴스 필드function-component.ts:39
currentComponent렌더링 한 번 (L100에서 채우고 L116에서 비움)모듈 변수:35
hookIndex렌더링 한 번 (L101에서 매번 0부터)모듈 변수:36

왜 굳이 전역인가? 개발자는 useState(0)라고만 쓴다. 인스턴스도, 칸 번호도 넘기지 않는다. 그래서 useState는 "지금 누구의 몇 번째 Hook인가"를 인자가 아닌 곳에서 알아내야 하고, 그 통로가 두 모듈 변수다. 렌더링은 한 번에 하나뿐이라 두 변수는 "지금 렌더링 중인 것" 하나만 가리키면 된다.

React 문서도 같은 구조를 설명한다: "Internally, React holds an array of state pairs for every component. It also maintains the current pair index, which is set to 0 before rendering." (react.dev, State: A Component's Memory, deep dive "How does React know which state to return?")

예제

옆으로 밀어 보기 →

const A = new FunctionComponent(() => {
  const [count, setCount] = useState(0);    // A의 Hook 0
  const [name] = useState("x");              // A의 Hook 1
  ...
});
const B = new FunctionComponent(() => {
  const [size] = useState(5);                // B의 Hook 0
  ...
});
A.mount(left);
B.mount(right);
// 그다음 A의 버튼을 한 번 클릭 → setCount(1)

시간표 (0 → 12)

왼쪽 상자는 모듈 변수, 오른쪽 상자는 인스턴스 필드다. 노란 줄은 방금 바뀐 값이다. 예측 칸이 나오면 먼저 고르고 넘어가자. 키보드 ← → 로도 움직인다.

되짚기

자기 말로 한 문장

에이전트에게 이 문장을 채워 보내자: "hookIndex는 ______ 때문에 전역이고, hooks는 ______ 때문에 인스턴스에 있다." 문장이 맞으면 이 레슨은 통과다.
