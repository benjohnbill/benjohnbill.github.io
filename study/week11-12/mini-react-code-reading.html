1. VNode: DOM 노드를 본뜬 값

요소 하나 → 객체 하나 · 글자 노드 하나 → 문자열 하나 · 주석 → 버림 (T3)

// src/vnode.ts:1-3
export type VNode =
  | string
  | { type: string; props: Record<string, string>; children: VNode[] };
  • type = 태그 이름, 소문자 (localName, T40)
  • props = 요소의 attribute 목록
  • children = 자식 노드 전부. 요소와 글자가 DOM 순서대로 섞임 (T11)
  • 문자열 = 글자 노드 하나. 태그 안의 값이 아니라 요소와 나란한 형제 노드 · <p>a<b>c</b>d</p> → children: ["a", {b}, "d"]

3. attribute와 property

  • attribute = HTML에 적힌 이름과 값 · getAttribute로 읽음 · 값은 항상 문자열 → props의 타입이 Record<string, string>
  • property = JS 객체의 필드 · input.value = 지금 칸에 보이는 글자 · 둘을 가르는 것은 dirty value flag
  • 예외 하나: 텍스트 입력칸이면 props.value에 attribute 대신 property를 넣음 (vnode.ts:44-46) → 사용자가 친 글자도 화면 상태라서 VNode에 담음 · T18, T19

5. 실제 React와의 차이

React element도 type과 props가 있고 글자는 문자열 (react.dev: createElement). 다른 점은 셋.

  • children 위치: React는 props.children 안 · 이 코드는 props와 나란한 children
  • props 값: React는 onClick 같은 함수와 객체도 가능 · 이 코드는 문자열만
  • type: React는 함수(컴포넌트)도 가능 · 이 코드는 태그 이름만 (함수 컴포넌트는 Phase 2의 FunctionComponent)
